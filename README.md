📖 软件简介
“20护眼小助手” 是一款专为长时间面对电脑屏幕的人群（上班族、学生、程序员等）设计的 Windows 桌面护眼软件。它基于国际公认的“20-20-20护眼法则”开发，旨在通过强制提醒、时间统计、外观美化及全屏护眼滤镜等功能，帮助用户养成良好的用眼习惯，有效缓解视疲劳。

✨ 核心功能
自动休息提醒（20-20-20法则）

默认每连续用眼 20 分钟，自动弹出全屏黑屏并进入 20 秒强制休息。

休息期间检测到任何鼠标、键盘操作，倒计时将自动重置为 20 秒，确保真正做到远眺放松。

丰富的护眼滤镜

内置 Windows 底层色彩调节引擎，支持 原色、黑白 两种屏幕色彩模式。

支持 蓝光过滤，并可自定义强度（0~100）。

提供 6 种色温颜色选项（淡黄、暖黄、护眼绿、暖橙色、橙色、薄荷绿）。

支持设置 护眼时间段，到点自动开启，过点自动关闭。

离开与空闲检测

工作暂停：鼠标键盘无操作达到设定时间，自动暂停工作倒计时。

离开锁屏：无操作超时提示待机，20 秒无响应自动进入锁屏模式，轮播展示必应（Bing）每日高清壁纸。

多维度使用统计

自动记录每日/每周/每月的 工作、休息、离开 次数及累计时长。

数据本地保存（不联网上传），支持一键清空周期记录。

精美的 UI 与沉浸式体验

支持 浅色、深色、浅蓝、浅绿、淡黄、淡粉、淡橙 7 种主题配色。

倒计时采用 滚动切换数字时钟 效果。

主界面最小化时，桌面会悬浮一个可随意拖动的半透明数字时钟。

贴心系统集成

支持系统托盘运行，右键菜单快捷操作。

支持开机自启动，主界面透明度调节。

底部内置百度百科直达链接，帮助快速了解护眼知识。

🚀 操作指南
主界面按钮：

⏸ 暂停 / ▶ 继续：随时手动暂停或恢复 20 分钟工作倒计时。

🚪 离开一会：立即进入必应壁纸全屏锁屏。此时按 ESC 键即可退出并恢复工作。

📊 统计：查看今日、本周、本月的用眼与休息数据。

最小化到托盘：将程序隐藏至右下角任务栏通知区域，不影响正常工作。

托盘图标右键菜单：

提供显示主窗口、统计、设置、软件说明、打开官网、退出等功能。

悬浮时钟：

点击主窗口标题栏的“最小化”按钮，会在桌面右下角生成悬浮时钟。

用鼠标左键按住可以任意拖动位置；双击悬浮时钟即可恢复主界面。
